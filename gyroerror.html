Golden Rules

  • Compass Best, Error West

    If Gyro/Mag bearing is numerically LARGER than True bearing, the error is WEST (-).

  • Compass Least, Error East

    If Gyro/Mag bearing is numerically SMALLER than True bearing, the error is EAST (+).

  • Applying Errors to Courses

    To get True Course: ADD East errors, SUBTRACT West errors from Gyro/Mag.
